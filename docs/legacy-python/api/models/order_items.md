# OrderItems

Bron: [order_items.py](../../../../legacy/api/models/order_items.py)

## Beschrijving

De producten die in een order zitten. Per regel: welk product en hoeveel.

## taken
- items van een order ophalen
- items van een order zetten
- items van een order verwijderen

## Opmerkingen

Dit is niet de order zelf, alleen de regels erin.
