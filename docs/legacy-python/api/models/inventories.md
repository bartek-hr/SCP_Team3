# Inventories

Bron: [inventories.py](../../../../legacy/api/models/inventories.py)

## Beschrijving

Voorraad van producten op een plek in het warehouse. Niet alleen wat er nu ligt, maar ook wat eraan komt, besteld is of al gereserveerd is.

## taken
- alle voorraad ophalen
- voorraad van een product op een locatie ophalen
- voorraad van een product op alle locaties ophalen
- totalen van een product ophalen
- voorraad toevoegen
- voorraad aanpassen
- voorraad verwijderen

## Opmerkingen

Voorraad hoort altijd bij een product én een locatie.
