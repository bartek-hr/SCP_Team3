# ShipmentItems

Bron: [shipment_items.py](../../../../legacy/api/models/shipment_items.py)

## Beschrijving

De producten die in een zending zitten. Per regel: welk product en hoeveel.

## taken
- items van een zending ophalen
- items van een zending zetten
- items van een zending verwijderen

## Opmerkingen

Dit is niet de zending zelf, alleen de regels erin.
