# Orders

Bron: [orders.py](../../../../legacy/api/models/orders.py)

## Beschrijving

Bestellingen. Wie bestelt, waar het heen moet, status, en uit welk warehouse het komt.

## taken
- alle orders ophalen
- één order ophalen
- items in een order ophalen
- orders van een klant ophalen
- een order toevoegen
- een order aanpassen
- items in een order updaten
- een order verwijderen

## Opmerkingen

Als de items van een order veranderen, wordt ook de gereserveerde voorraad bijgewerkt.
