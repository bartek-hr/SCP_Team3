# Locations

Bron: [locations.py](../../../../legacy/api/models/locations.py)

## Beschrijving

Plekken in een warehouse, zoals een zone, gang of rek.

## taken
- alle locaties ophalen
- één locatie ophalen
- locaties in een warehouse ophalen
- een locatie toevoegen
- een locatie aanpassen
- een locatie verwijderen

## Opmerkingen

Een locatie hoort bij één warehouse. Hoeveel er ligt, staat bij inventories.
