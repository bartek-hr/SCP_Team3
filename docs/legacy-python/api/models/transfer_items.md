# TransferItems

Bron: [transfer_items.py](../../../../legacy/api/models/transfer_items.py)

## Beschrijving

De producten die in een transfer zitten. Per regel: welk product en hoeveel.

## taken
- items van een transfer ophalen
- items van een transfer zetten
- items van een transfer verwijderen

## Opmerkingen

Dit is niet de transfer zelf, alleen de regels erin.
