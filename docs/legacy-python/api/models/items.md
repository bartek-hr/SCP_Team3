# Items

Bron: [items.py](../../../../legacy/api/models/items.py)

## Beschrijving

De echte producten. Denk aan naam, barcode, gewicht en van welke leverancier het komt.

## taken
- alle producten ophalen
- één product ophalen
- producten van een lijn ophalen
- producten van een groep ophalen
- producten van een type ophalen
- producten van een leverancier ophalen
- een product toevoegen
- een product aanpassen
- een product verwijderen

## Opmerkingen

Een product kan bij een lijn, groep, type en leverancier horen.
